# Osaio UI 测试报告使用指南

## 概述

本项目提供了强大的可视化测试报告生成功能，支持HTML和JSON格式的测试报告。

## 功能特点

1. **HTML可视化报告**
   - 美观的UI设计
   - 响应式布局，支持移动设备
   - 详细的测试统计信息
   - 饼图展示测试结果分布
   - 支持测试步骤记录
   - 支持截图展示

2. **JSON数据报告**
   - 结构化的测试数据
   - 易于解析和处理
   - 支持集成到其他系统

3. **自动集成pytest**
   - 自动捕获测试结果
   - 自动保存失败截图
   - 无需修改现有测试代码

## 使用方法

### 方法1: 手动使用报告生成器

```python
from utils.report_generator import TestReportGenerator

# 创建报告生成器
report = TestReportGenerator(
    report_dir="reports",
    report_title="Osaio UI 测试报告"
)

# 开始报告
report.start_report()

# 添加测试结果
report.add_test_result(
    test_name="test_login_success",
    status="passed",
    duration=3.5,
    steps=[
        report.add_test_step("打开登录页面", "passed", 1.0),
        report.add_test_step("输入账号密码", "passed", 1.5),
        report.add_test_step("点击登录按钮", "passed", 0.5),
        report.add_test_step("验证首页显示", "passed", 0.5)
    ]
)

# 添加失败的测试结果
report.add_test_result(
    test_name="test_login_failed",
    status="failed",
    duration=2.0,
    error_message="AssertionError: Expected home page but still on login page"
)

# 结束报告
report.end_report()

# 生成HTML报告
html_path = report.generate_html_report()

# 生成JSON报告
json_path = report.generate_json_report()
```

### 方法2: 自动集成pytest

#### 步骤1: 启用报告插件

将 `conftest_report.py` 文件内容复制到项目的 `conftest.py` 文件中，或者使用以下命令运行测试：

```bash
pytest tests/ --conftest=conftest_report.py
```

#### 步骤2: 运行测试

```bash
# 运行所有测试
pytest tests/ -v

# 运行特定测试
pytest tests/test_main.py -v

# 生成报告
pytest tests/ --conftest=conftest_report.py
```

测试完成后，会自动在 `reports` 目录生成HTML和JSON报告。

### 方法3: 在测试中手动记录步骤

```python
from utils.report_generator import TestReportGenerator, TestReportHook

class TestLogin:
    def test_login_success(self, driver):
        # 创建报告钩子
        report = TestReportGenerator()
        hook = TestReportHook(report)
        
        # 开始测试
        hook.start_test("test_login_success")
        
        try:
            # 步骤1
            hook.add_step("打开登录页面", "passed", 1.0)
            login_page = LoginPage(driver)
            
            # 步骤2
            hook.add_step("输入账号密码", "passed", 1.5)
            login_page.login("test@example.com", "password")
            
            # 步骤3
            hook.add_step("验证首页显示", "passed", 1.0)
            assert home_page.is_home_displayed()
            
            # 结束测试
            hook.end_test("passed", 3.5)
            
        except Exception as e:
            # 记录失败
            hook.add_step("测试失败", "failed", 0, str(e))
            hook.end_test("failed", 3.5, str(e))
            raise
        
        finally:
            # 生成报告
            report.generate_html_report()
```

## 报告内容

### HTML报告包含：

1. **报告头部**
   - 报告标题
   - 生成时间

2. **统计卡片**
   - 总测试数
   - 通过数量
   - 失败数量
   - 跳过数量
   - 错误数量
   - 通过率
   - 总耗时

3. **饼图展示**
   - 测试结果分布可视化

4. **测试详情**
   - 测试名称
   - 测试状态
   - 测试耗时
   - 错误消息（如果有）
   - 测试步骤
   - 截图（如果有）

## 故障排除

### 问题1: 报告生成失败

**解决方案**:
- 检查 `reports` 目录权限
- 确保有足够的磁盘空间
- 检查Python环境和依赖

### 问题2: 截图无法显示

**解决方案**:
- 检查截图文件是否存在
- 确认截图路径正确
- 使用相对路径而非绝对路径

### 问题3: 中文乱码

**解决方案**:
- 确保HTML文件使用UTF-8编码
- 在浏览器中设置正确的编码
